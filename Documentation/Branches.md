
# Branching logic for project

Main branch is for development of the main code progress. When releases
get more mature, there will be release-X.Y branches, and only code fixes will
be promoted.

## Current branches:

* main: primary release path

* makernotes: Holding patches for implementing makernotes callback, currently
  in LibRaw main.

* local-lib: branch for working on having SwiftLibRaw compile LibRaw and 
  provide the binaries upstream.
