
# Welcome to SwiftLibRaw

SwiftLibRaw is 
SwiftLibRaw is a Swift package wrapping the
[LibRaw](https://github.com/LibRaw/LibRaw)
C and C++ library. LibRaw processes a multitude of RAW photo formats, providing
access to metadata and picture data.

This package makes use of the
[C++ interoperability](https://www.swift.org/documentation/cxx-interop/)
feature introduced in Swift 5.9.

Currently the project is Mac-only and was developed using Swift 6.2 features.
